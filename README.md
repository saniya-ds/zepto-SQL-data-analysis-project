# Zepto E-commerce Data Analysis Using SQL

## Project Overview

This is my first SQL data analysis project, based on a
Zepto e-commerce inventory dataset.

The project focuses on exploring inventory data using
PostgreSQL to understand product information, pricing,
discounts, and stock availability.

I completed this project as part of my learning journey
in Data Analytics, following an online project tutorial.

## Objectives

- Explore and understand the dataset.
- Practise SQL queries on real-world-style data.
- Analyse product prices and discounts.
- Examine product availability and inventory information.
- Develop practical SQL and data analysis skills.

## Tools Used

- PostgreSQL
- SQL
- CSV dataset

## Skills Practised

- Data exploration
- Data cleaning, where applicable
- Filtering and sorting data
- Aggregate functions
- Grouping data
- Writing analytical SQL queries

## Project Files

- `zepto_sql_data_analysis.sql` - SQL queries used
  in the project.

This project helped me practise using SQL to explore
structured data and answer questions about product
pricing, discounts, and inventory.

It also helped me understand how SQL can be applied
to e-commerce data analysis.
